# Idempotent Task Grid

A single-node FastAPI application that handles computation jobs asynchronously with concurrency, idempotency, and background processing.

## Requirements Addressed

1. **O(1) Ingestion**: `POST /api/v1/jobs` endpoints handle requests in <50ms by delegating heavy processing to background tasks and utilizing Redis for O(1) atomicity (e.g. SET with NX flag and Hash operations).
2. **Exactly-Once Idempotency**: Handled using a combination of the Bearer token and the `Idempotency-Key` header. Requests with duplicate keys return the current status of the job initialized by the original request.
3. **Rate Limiting**: Enforced via a sliding minute-window in Redis pipeline per token, limited to 5 requests / min. Returns `429 Too Many Requests` on exceeding.
4. **Background Task**: Built using FastAPI's built-in `BackgroundTasks` executing `asyncio.sleep(7)` non-blockingly and hashing the payload with SHA-256 before updating Redis.

## Tech Stack
- **Python 3.12+**
- **FastAPI** (Web framework)
- **Redis** (Used for caching idempotency keys, storing job status, and atomic rate limiting checks)
- **Docker & Docker Compose** (Containerization & Orchestration)

## Running the API

You can start the API and Redis instance using Docker Compose:

```bash
docker-compose up -d --build
```

The API will be available at `http://localhost:8000`.

### API Documentation (Swagger UI)
Interactive API documentation is automatically generated by FastAPI:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## Usage Examples

### 1. Submit a Job
```bash
curl -X POST http://localhost:8000/api/v1/jobs \
  -H "Authorization: Bearer test-token-123" \
  -H "Idempotency-Key: e8c2a8f8-3e4b-4a9a-b4d5-8f6a3c6b2d1e" \
  -H "Content-Type: application/json" \
  -d '{"payload": "string to be hashed"}'
```

**Response (202 Accepted):**
```json
{
  "job_id": "c1f7b8e2-9d3a-4e5c-a1b2-c3d4e5f6a7b8",
  "status": "pending"
}
```

### 2. Check Job Status
```bash
curl http://localhost:8000/api/v1/jobs/c1f7b8e2-9d3a-4e5c-a1b2-c3d4e5f6a7b8
```

**Response (200 OK):**
```json
{
  "job_id": "c1f7b8e2-9d3a-4e5c-a1b2-c3d4e5f6a7b8",
  "status": "completed",
  "result": "..."
}
```
